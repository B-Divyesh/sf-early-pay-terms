Policy / 29 August 2026

Privacy policy

Your invoice figures stay in this browser during normal calculator use.

Data on this device

Your browser stores the current calculation when site storage is available. A verified Plus license also makes saved versions and templates available.

A license token and its last check remain in this browser so restoration survives reload.

Demo data

The demo uses a separate browser database named demo:early-pay-terms. Reset demo clears only that sample database. Starting for real clears the sample database before opening the calculator.

License checks

When you restore a license, only its token is sent to Sociobot’s product verification endpoint. Early Pay Terms does not send invoice figures with that request.

A valid result remains in this browser after reload. Invalid tokens stay locked, and connection errors are shown.

Exports and deletion

JSON and CSV exports are created in your browser. JSON does not include a license token.

Clear local data erases the current calculation, saved versions, and templates. It does not remove the license.

Network and offline use

After the first visit, the browser keeps the app files needed to reopen the calculator offline.

This site has no analytics, advertising pixels, remote fonts, or third-party runtime scripts.

Contact

For privacy questions, contact privacy@sociobot.in.
