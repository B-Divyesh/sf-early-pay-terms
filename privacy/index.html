Privacy policy

Your invoice figures stay in this browser during normal calculator use.

Data on this device

Your browser stores the current calculation, saved versions, and templates when site storage is available. It separately stores an optional license token and its last verification result.

Demo data

The demo uses a separate browser database named demo:early-pay-terms. Reset demo deletes only that sample database. Starting for real deletes the sample database before opening the calculator.

License checks

When you restore a license, its token is sent to Sociobot’s billing API to check whether it is valid. Early Pay Terms does not send invoice figures with that request. Plus is not available to buy in this release.

Exports and deletion

JSON and CSV exports are created in your browser. JSON does not include a license token. Use Clear local data to erase the current calculation, saved versions, and templates.

Network and offline use

After the first visit, the browser keeps the app files needed to reopen the calculator offline. This site has no analytics, advertising pixels, remote fonts, or third-party runtime scripts.

Contact

For privacy questions, contact privacy@sociobot.in.
